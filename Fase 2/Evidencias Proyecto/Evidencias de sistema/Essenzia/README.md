# Evidencias de desarrollo – Essenzia

## Descripción del proyecto

Essenzia es una plataforma web de comercio electrónico especializada en perfumes de diseñador, árabes y de nicho.

## Funcionalidades implementadas

1. **Página principal:** interfaz de usuario con diseño responsive y navegación entre secciones.
2. **Catálogo de perfumes:** visualización de 30 fragancias con imágenes y características.
3. **Sistema de filtros:** búsqueda y clasificación de productos según categoría, género, familia olfativa, ocasión y clima.
4. **Detalle de perfumes:** información del producto, notas olfativas y pirámide olfativa interactiva.
5. **Essenzia Match:** cuestionario de cinco preguntas que recomienda fragancias según las preferencias del usuario.
6. **Discovery Box:** selección personalizada de cinco muestras de perfumes.
7. **Carrito de compras:** implementación inicial mediante almacenamiento local del navegador.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git y GitHub
