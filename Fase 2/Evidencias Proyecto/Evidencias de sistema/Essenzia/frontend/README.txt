ESSENZIA - Prototipo frontend

1. Abre la carpeta essenzia_frontend en VS Code.
2. Instala la extensión Live Server.
3. Abre index.html con Open with Live Server.
4. No necesitas npm ni Node.js para esta etapa.
5. Catálogo, búsqueda, filtros y carrito local funcionan con datos de prueba.
6. Las ilustraciones de frascos están hechas con CSS; sustituir por fotos reales más adelante.
7. El checkout, el quiz y la conexión SQLite todavía no están implementados.
